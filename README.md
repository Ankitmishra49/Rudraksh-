## 🚀 Quick Start (5 Minutes)

### 1. Setup Environment
```bash
# Clone/download files
# Install dependencies
npm install

# Create .env file
cp .env.example .env

# Fill in your API keys:
REACT_APP_CLAUDE_API_KEY=sk-ant-...
REACT_APP_RAZORPAY_KEY_ID=rzp_live_...
REACT_APP_FIREBASE_PROJECT_ID=...
```

### 2. Run Locally
```bash
npm run dev
# App runs on http://localhost:3000
```

### 3. Test Story Generation
- Select character, setting, action
- Click "Create Story"
- Claude AI generates story in seconds

### 4. Deploy
```bash
# Frontend (Vercel)
vercel deploy --prod

# Backend (Railway)
railway deploy

# See DEPLOYMENT_GUIDE.md for detailed steps
```

## 🚀 Deployment (Quick Path)

### 1. Frontend → Vercel (5 min)
```bash
npm install -g vercel
vercel deploy --prod
```

### 2. Backend → Railway (10 min)
```bash
npm install -g railway
railway init && railway deploy
```

### 3. Database → Firebase (15 min)
- Create project at console.firebase.google.com
- Enable Firestore + Storage
- Copy config to .env

### 4. Payments → Razorpay (5 min)
- Create account at razorpay.com
- Get API keys
- Add to .env

**Total setup time: ~30 minutes**

See `DEPLOYMENT_GUIDE.md` for detailed, step-by-step instructions.

## 💬 Support & Help

### Common Questions

**Q: How much does Claude API cost?**
A: ~₹10-30 per story generated. At 5K stories/month = ₹50-150K

**Q: Can I change the app name/branding?**
A: Yes! Fully customizable. Replace "कहानियों का जादू" with your brand name.

**Q: How do I make stories in Hindi?**
A: Already included! App detects user language preference and generates in Hindi/English.

**Q: Can I add more languages?**
A: Yes! Add to the `content` object in kids-story-app.jsx, and update Claude prompt.

**Q: When will I be profitable?**
A: Year 2, assuming 20% free→paid conversion. See BUSINESS_PLAN.md for details.
